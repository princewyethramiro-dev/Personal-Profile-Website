## Features
- **Three pages:** Home, About, and Projects, linked by one navigation menu.
- **Responsive layout:** works on three devices: phone, tablet, and desktop. Additionally, hamburger menu is present in mobile version.
- **Greeting button that tells time:** "Say Hello" on the Home page shows a good morning, afternoon, or evening greeting.
- **Show/Hide details:** "Show Details" on a project card reveals or hides the project type, status, and purpose.
- **Projects page:** project cards and a project list table.

## User Role
The site is static as the only user's main role is the **Visitor**, who can view every page and use both buttons.

## Setup and Run
Fortunately, no installation is needed as you only need a web browser and an internet connection.

### Option 1: Open the live site
Go to https://princewyethramiro-dev.github.io/Personal-Profile-Website/

### Option 2: Run it on your computer
1. Download the project: click **Code > Download ZIP** on GitHub and extract it.
   Or clone it:
   ```bash
   git clone https://github.com/princewyethramiro-dev/Personal-Profile-Website.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.
   (Optional: in Visual Studio Code, install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.)

## How to Use
1. Open the Home page. Click **Say Hello** to see a greeting for the time of day.
2. Use the menu (**Home**, **About**, **Projects**) to move between pages. On a phone, tap the menu button first.
3. On the Projects page, click **Show Details** on a card to see more information. Click **Hide Details** to close it.
